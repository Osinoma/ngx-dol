# Next steps (v1.1 and beyond)

*Plain-language note: what the next versions add, so v1.0 is understood as a first release.*

1. **Symbol-change linkage.** A permanent security ID linking renamed symbols (for example ACCESS to ACCESSCORP, GUARANTY to GTCO, FBNH to FIRSTHOLDCO), built from NGX corporate-action notices.
2. **Corporate-action adjustment.** Bonus, split and rights adjustments, giving an adjusted-price and total-return series.
3. **Pre-2016 market capitalisation.** Back-fill shares outstanding from annual reports or NGX's sector market-cap reports (folder 7).
4. **ETF and bond panels.** The same reports carry ETFs and FGN bonds; parse them as companion panels.
5. **Annual update.** Re-run each January and release v1.x with a new Zenodo version under the same concept DOI.
6. **Bid-ask proxies.** Add Corwin-Schultz and Roll spread estimates from the daily high and low.
